# Valentine's Day Page

A playful, interactive Valentine's Day webpage built as a small single-page project.

**Live page:** https://sharonmathew023-blip.github.io/valentine/

## Features

- A Valentine's question with two response buttons.
- Playful interaction when the visitor chooses the negative response.
- Celebration state with confetti.
- Responsive layout for mobile and desktop.
- No account, database, or application server required.

## Technology

- HTML
- CSS
- Vanilla JavaScript
- [canvas-confetti](https://www.npmjs.com/package/canvas-confetti) via jsDelivr CDN

## Run locally

Clone the repository, then serve its root directory:

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## Deployment

The static site is published through GitHub Pages from the `main` branch.
