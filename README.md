# Valentine's Day Page

A playful, interactive Valentine's Day webpage built as a small single-page project.

**Live page:** https://sharonmathew023-blip.github.io/valentine/

## Features

- A simple Valentine's question and two response buttons.
- Playful interaction when the visitor chooses the negative response.
- Celebration state with confetti.
- Responsive layout for mobile and desktop.
- No account, database, or server-side application required.

## Run locally

Clone the repository and open `index.html` in a browser. For a local web server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Tech

- HTML
- CSS
- Vanilla JavaScript
- [canvas-confetti](https://www.npmjs.com/package/canvas-confetti) via jsDelivr CDN

## Deployment

The project is a static site and is published with GitHub Pages from the `main` branch.
